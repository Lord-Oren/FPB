# 0.19.0 — local review

The server can store, validate, publish and restore 66 short website texts. An empty override returns to its original wording. The Site wording editor and public-page integration are the next interface step; this is not yet an end-to-end editable-text release.

This package also includes the reviewed local interface updates: honest uncertain-delivery labels and a confirmed resend action, icon-only social links with accessible names, and the phone-only emblem and stepped shoreline. The hosted site now serves an icon. HTTP keep-alive is extended and startup diagnostics record safe stage/error codes without connection strings.

The live deployment remains 0.18.0 (commit 1b45277); no new push or provider setting change is included. Forms, outgoing email and notifications remain disabled. The approved Contact address is frogpondboys@gmail.com. A human authenticated Desk acceptance test remains outstanding.

The earlier startup failure is confirmed in provider logs; its exact cause is not known. The HTTP change follows Render guidance but is not proof of the historical cause or a guarantee of uninterrupted deployments. Cloudflare analytics injection was reported during the prior browser check, but was absent in the current curl response; analytics settings could not be read with the current token. No CSP restriction was weakened.
